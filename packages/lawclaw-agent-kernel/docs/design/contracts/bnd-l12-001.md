# BND-L12-001：L1 ↔ L2 Cognitive Runtime

## 操作族

L1 通过 Runtime Control 派发、恢复、取消和检查 Attempt；L2 通过 Runtime Event 追加规范化 Attempt 事件。具体方法与DTO见[CD-1](component-development-contracts-v1.md)，候选待批准。

## 核心语义

- L1 冻结 `ToolCatalogSnapshotRef` 后随派发交给 L2；L2 不直接查询 L3。
- L2 将 `ToolCallCandidate` 作为规范化事件交回 L1 并暂停 Step；L1完成权限与工具执行后，由Core决定下一已提交InvokeModel；L2不能自行恢复循环调用模型。
- 事件由RunRegistry分配Run级sequence；Attempt与command为因果身份，L2流index不作为Run序号，持久化成功后才确认；跨 Run 无全局顺序。
- 首版进程内调用；隔离 Pi Runtime 时用有界 stdio JSONL。断线表示未知，恢复前检查 Attempt/ToolCall 权威状态。
- 首版本地claim30秒/10秒续期，接管递增fence；不引入跨机租约。
