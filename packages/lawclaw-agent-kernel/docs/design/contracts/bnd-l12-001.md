# BND-L12-001：L1 ↔ L2 Cognitive Runtime

## 操作族

L1 通过 Runtime Control 派发、恢复、取消和检查 Attempt；L2 通过 Runtime Event 追加规范化 Attempt 事件。具体方法签名和 DTO 待步骤二确认。

## 核心语义

- L1 冻结 `ToolCatalogSnapshotRef` 后随派发交给 L2；L2 不直接查询 L3。
- L2 将 `ToolCallCandidate` 作为规范化事件交回 L1 并暂停 Step；L1 完成权限与工具执行后把 `ToolResultRef` 或拒绝恢复给原 Attempt。
- 事件按 `(runId, attemptId, sequence)` 有序，持久化成功后才确认；跨 Run 无全局顺序。
- 首版进程内调用；隔离 Pi Runtime 时用有界 stdio JSONL。断线表示未知，恢复前检查 Attempt/ToolCall 权威状态。
- 单 Worker 不强制 Lease；多 Worker 或崩溃接管时才启用 fence。
