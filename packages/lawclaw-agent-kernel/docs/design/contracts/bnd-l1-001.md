# BND-L1-001：L1 内部组件

L1 组件通过 Command Port、Repository Port 和 Domain Event Port 协作。首版绑定为进程内强类型调用、本地有界队列和 SQLite 本地事务；不以消息队列拼接聚合事务。

状态变更与其持久事件必须原子提交，提交后才能通知。队列只是可运行提示，Run Store/Event Journal 才是权威来源。FlowEngine 保持无状态；Session 不绑定进程。写命令以稳定 ID 去重，旧 attempt/version/fence 写入拒绝。
