# BND-L13-001：L1 Control / PEP ↔ L3 Tool Runtime

## 操作族

Tool Runtime 提供可见工具描述与已授权工具执行；只有声明异步能力的长任务工具提供受理、查询、取消和事件流。具体签名待步骤二确认。

## 语义

唯一合法动作路径为 `L2 Candidate → L1/PEP → L3 → L4 → L1 Resume → L2`。L2 不直连 L3，L1 不直连 L4。每次执行携带稳定 `toolCallId`、Provider operation key 和有效 Permit。L3 只消费授权结果；Provider DTO 不进入公共模型。结果先持久化再发布，超大结果转 Artifact。副作用超时先查询；无法确认时进入 `UNKNOWN_SIDE_EFFECT`，禁止盲重试。
