## TEST-P1-01：满载扫描算法不能满足既定恢复验收

- 位置：`layers/l1-control/components/run-registry.md`，CD-1 第 5 节及 TC-06（初审行 96、125）。
- 问题：每秒扫描 256 条，覆盖 4096 条至少需要 16 轮，无法保证 5 秒发现。测试只说“丢 wake”，没有规定活动集、游标位置，空库用例会通过而满载失效。
- 反例：4096 个活动 Run，唯一丢失提示的 Run 紧邻当前游标之前，无新流量。5 秒只扫描 1280 条，尚未发现目标。
- 修订：保留每页 256 条，但明确每次 tick 的页数、时间预算、公平游标推进以及 5 秒承诺成立的依赖健康条件；或统一调大恢复目标，不允许正文和验收各用不同数字。增加满载用例：4096 条、所有游标边界、提示队列满、连续插入；断言扫描发现时间，单独断言实际派发受资源限制，不把“发现”写成“执行”。

## TEST-P1-02：SFMEA 分数没有失效依据，无法支撑风险门槛

- 位置：RunRegistry/ContextEngine/SubagentCoordinator/ExecutionPermit/ToolCallRuntime/AgentRuntime 各 CD-1 第 8 节；例如 `execution-permit.md` TC-02、TC-06。
- 问题：各组件六行重复同一组 S/O/D 数字；风险列只有编号，没有原因、局部影响、系统影响、检测与控制依据。“同 command 同绑定重投”标 S10，而“授权 epoch 撤销”标 S8，读者无法判断评分针对什么失效。写“设计估计”仍不能解释这些差异。当前使用 S≥9/RPN≥100 作门槛会遗漏未授权执行类风险。
- 反例：实现错误地沿用旧 epoch 的成功回执，真实副作用发生；该行 RPN96、S8 未触发门槛，而正常幂等行为的行触发门槛。
- 修订：共享一张量表，逐行明确“失效”及后果，例如“旧 epoch 回执被当作新启动权→撤销后执行”；提供检测点、预防/恢复控制与对应 TC。缺乏发生率数据时 O/D 标待评，不伪造 RPN；对越权、重复副作用、权威数据损坏、无法收敛单独设置不依赖 RPN 的强制验收门槛。纯正常路径从 SFMEA 风险行分出，或写明其要捕获的真实失效。无需部署监控系统即可完成该设计。

## TEST-P1-03：UNKNOWN 核对用例没有唯一的跨组件状态预期

- 位置：`layers/l3-tool-runtime/components/tool-call-runtime.md` CD-1 第 5 节、TC-04/05/06；`layers/l1-control/components/run-registry.md` CD-1 第 5 节；CD-1 `ExecutionQuery` 与 `resolveIncident`。
- 问题：TC-04 要求 UNKNOWN 后“回收原结果”，正文同时要求终态不能回退；未明确 UNKNOWN 是否为可细化事实、谁将 ToolCall 变为 succeeded/failed、核对后如何生成稳定 ToolObserved，及 Run 已终态时哪些对象可更新。仅断言 Provider 不重调不足以验收恢复正确性。
- 反例：工具已生效→丢响应→Tool UNKNOWN、Run 已取消→Provider 后续返回可信成功。实现 A 只存 Artifact 仍返回 UNKNOWN，实现 B 修改 ToolCall 并再次发布完成事件；现有短句不能判定谁符合设计，亦不能检查重复核对是否二次消费。
- 修订：增加状态表和具名用例，固定以下分支的 ToolCall phase/effect/version、Run version、Incident 状态、ToolObserved eventId/数量与 Provider 调用数：①活跃 Run 取得可信结果；②Run 已终态取得可信结果；③不支持查询；④返回矛盾结果；⑤核对提交成功丢 ACK 后再次核对；⑥结果 Artifact 发布成功但结果事务失败后重启。定义核对入口和授权者，明确状态更新与通知的持久化顺序。外部查询用替身即可，不扩展 Provider 实现范围。

## TEST-P2-01：统一性能条款缺少可重复的负载基准

- 位置：各 CD-1 第 8 节“80% 服务能力下持续 30 分钟”。
- 问题：服务能力未定义测量方法、动作组合、输入大小与依赖延迟；实现越慢，其 80% 压力越低，无法比较容量目标。P99 指标也未明确排队是否计入。
- 修订：在 Kernel 测试附件定义固定动作组合、最大合法输入、替身延迟、到达率/并发、预热及排队时间口径。分别报告纯计算、持久提交、端到端时间。保留机器元数据及原始样本；不要求运维平台或真实外部压测。
