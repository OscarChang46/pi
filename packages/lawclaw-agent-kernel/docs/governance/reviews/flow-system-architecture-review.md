| SR | 用户/场景 | 接口与持久事实 | 内部结构/测试定位 |

| SR-03 | 作者S7多节点回环；S8自环；S9非法路径/上限 | TaskGraph/上下文；binding与visit检查点 | 图规则/Map分派；AK-FS-006～008 |
| SR-04 | 组合调用方S10关联成功；S11等待；维护方S12跨提交恢复；S13终止竞争 | 计划Port/受控journal；三表与结果消费 | Coordinator/GraphRules；FE-SCH-TC-01～08待写 |

每个SR保留场景、功能、接口、类图、算法、流程、读写、韧性、升级/回退、测试设计及可测试手段。SR-01～03当前接口引用源码，新增关联协议集中SR-04；不新增一套全项目数据开发规范。

具体走读：A输入0正常返回1，路由到B；B返回2后路由到A；A第二次返回3并EXIT。计划visit为1/2/3，三个独立runId；每Run的第一项Activity可以都是sequence=1，但不能跨Run复用结果。第3次是新激活；第2次Run完成后进程崩溃，恢复只消费它的原结果并登记第3次，不重新执行B。

扩展走读：增加C工作流只新增外部目录注册、版本与图定义/边，不增加系统态，不改Coordinator指令选择。新增一种系统控制指令属于封闭协议变更，必须增加常量、契约、表项、迁移及负向用例；不能承诺任意扩展不修改框架。
