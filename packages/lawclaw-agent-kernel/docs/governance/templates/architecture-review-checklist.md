# 架构评审清单

## 职责与依赖

- [ ] 变更归属到唯一子系统，明确列出禁止职责。
- [ ] 没有绕过 Port、Composition Root 或总体允许依赖。
- [ ] 没有循环依赖和具体 Runtime 类型泄漏。
- [ ] 外部职责变化已经更新总体 Draw.io；否则已说明无需更新。

## 接口与数据

- [ ] 公开接口含完整中文契约。
- [ ] 方法语义、幂等、并发、取消、错误和版本明确。
- [ ] 权威状态、投影、事务、租户键和保留策略明确。
- [ ] 数据流、控制流和故障流都有图或序列说明。

## 安全与韧性

- [ ] 默认拒绝、最小权限、路径/出口/工具白名单明确。
- [ ] Secret、Prompt、正文和工具参数不进入日志。
- [ ] 循环、队列、Buffer、输出、重试、子 Agent 均有界。
- [ ] 超时、取消、部分失败、崩溃和回退语义明确。

## 验证与基线

- [ ] 上层约束追踪覆盖率 100%。
- [ ] 受影响测试和跨租户负向测试通过。
- [ ] 质量指标在批准的波动预算内。
- [ ] 图、文档、Schema、代码和测试一致。
- [ ] ACR、ADR、证据和基线登记已经同步。
